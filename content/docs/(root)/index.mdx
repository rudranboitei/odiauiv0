**odiaui** is a component library inspired by the art, temples, and craft of
Odisha — the Konark wheel, temple silhouettes, handloom patterns, and the
colors of Pattachitra. Every component ships as source code, so you own the
code and can shape it to fit your project.

## What You Get

- 🛕 **Heritage design** — Konark wheel artwork, temple motifs, and a palette
  drawn from Odisha's craft traditions
- 🛠️ **Own the code** — every component is copied into your project, so you
  can customize it freely
- ♿ **Accessible** — keyboard support and proper focus states out of the box
- 🌗 **Themeable** — CSS variables for light and dark mode
- ✨ **Delightful feedback** — animated icons, smooth transitions, and optional
  sound and haptic feedback
- 🤖 **Agent ready** — ships with `llms.txt`, `llms-full.txt`, an API catalog,
  and agent skill discovery

## Install a Component

```bash
npx shadcn@latest add https://odiaui.xyz/r/button.json
```

Then import it:

```tsx
import { Button } from "@/components/ui/button";

export function Example() {
  return <Button>Namaskar</Button>;
}
```

Browse the available components in the [Components](/docs/components) section.
