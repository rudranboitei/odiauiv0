**odiaui** is a shadcn/ui component library for Odisha. Components are distributed as source code, so you own the code and can shape it to fit your project.

## What You Get

- 📦 **shadcn/ui compatible** - Install with the shadcn CLI
- ♿ **Accessible** - Built on Radix primitives with keyboard support
- 🌗 **Themeable** - CSS variables for light and dark mode
- 📚 **Documentation site** - Powered by Fumadocs
- 🤖 **Agent ready** - Ships with `llms.txt`, `llms-full.txt`, an API catalog, and agent skill discovery
- 🔊 **Web audio feedback** - Interaction sounds powered by `@web-kits/audio`
- 📳 **Web haptics** - Optional haptic feedback via `web-haptics`
- ✨ **Motion animations** - Uses `motion` for animated UI states and transitions
- 🎯 **Animated icons** - Reusable animated icons for buttons, sharing, and navigation
- 🔄 **View transitions** - Uses Next.js view transitions for smoother page changes
- 🚀 **Deploy ready** - Deploy anywhere

## Tech Stack

- `Next.js 16` + App Router
- `React 19`
- `Tailwind CSS 4`
- `Fumadocs`
- `motion`
- `@web-kits/audio`
- `web-haptics`
- `shiki` + `rehype-pretty-code`

## Install a Component

```bash
npx shadcn@latest add https://odiaui.vercel.app/r/button.json
```

Then import it:

```tsx
import { RollingButton } from "@/components/ui/button";

export function Example() {
  return <RollingButton>Namaskar</RollingButton>;
}
```

Browse the available components in the [Components](/docs/components) section.
