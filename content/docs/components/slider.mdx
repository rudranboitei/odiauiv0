## Installation

```bash
npx shadcn@latest add https://odiaui.vercel.app/r/slider.json
```

## Usage

```tsx
import { Label } from "@/components/ui/label";
import { Slider } from "@/components/ui/slider";
```

```tsx
<Label htmlFor="darshan">Darshan queue length</Label>
<Slider id="darshan" defaultValue={60} />
```

Heritage is on by default: every thumb is a small medallion carrying a
cultural icon from the Badge component's set — a mini Konark wheel
(`chakra`) unless you say otherwise. Colours come only from theme
tokens, so the slider follows your light and dark theme automatically.

## Examples

### Range

Pass an array for a two-thumb range. `ticks` adds faint markers along
the track — dots at the ends, Ikat diamonds between, like beads on a
temple flag rope.

### Motifs

Any motif name from the Badge icon set works — `chakra` (default),
`padma`, `deula`, `pattachitra`, and more. Pass `motif="none"` for the
plain stock thumb.

<ComponentPreview name="slider-motifs">
  <SliderMotifs />
</ComponentPreview>

### Ticks

`ticks` takes a count and spreads that many markers evenly along the
track (horizontal sliders). They are purely decorative — grabber
logic, values, and keyboard steps all stay in Base UI's hands.

## API Reference

### Slider

Wraps Base UI's slider root with `thumbAlignment="edge"`. One thumb
renders per value, so arrays give you multi-thumb ranges.

| Prop           | Type                      | Default     | Description                                         |
| -------------- | ------------------------- | ----------- | --------------------------------------------------- |
| `motif`        | `BadgeIconName \| "none"` | `"chakra"`  | Cultural icon in each thumb.                        |
| `ticks`        | `number`                  | -           | Count of marker dots along the track (horizontal).  |
| `value`        | `number \| number[]`      | -           | Controlled value; an array renders multiple thumbs. |
| `defaultValue` | `number \| number[]`      | -           | Uncontrolled starting value(s).                     |
| `min` / `max`  | `number`                  | `0` / `100` | Value bounds.                                       |
| `className`    | `string`                  | -           | Additional classes merged onto the root.            |

All other Base UI slider props (`onValueChange`, `disabled`, `orientation`, and more) are forwarded. Set `orientation="vertical"` for a vertical slider — note that `ticks` is designed for horizontal tracks.
