## Installation

```bash
npx shadcn@latest add https://odiaui.vercel.app/r/sheet.json
```

Colours come only from shadcn theme tokens, so the sheet follows your
theme automatically in light and dark mode.

## Usage

```tsx
import {
  Sheet,
  SheetContent,
  SheetDescription,
  SheetHeader,
  SheetTitle,
  SheetTrigger,
} from "@/components/ui/sheet";
```

```tsx
<Sheet>
  <SheetTrigger render={<Button variant="outline" />}>Open</SheetTrigger>
  <SheetContent>
    <SheetHeader>
      <SheetTitle>Title</SheetTitle>
      <SheetDescription>Description</SheetDescription>
    </SheetHeader>
  </SheetContent>
</Sheet>
```

Heritage is on by default: every sheet carries a faint **rekha deula
watermark** — the curving temple tower flying its flag — behind the
content. Opt out with
`watermark="none"`; the **Ikat ornament strip** is available with
`ornament`.

Base UI uses the `render` prop instead of `asChild` — pass the element
you want the trigger to render as.

## Examples

### Bottom Sheet

`side="bottom"` rounds the top edge, and `handle` adds a grabber bar
(visual only). The Ikat ornament strip can be added with `ornament`, and
`watermark="chakra"` swaps the deula temple for a Konark wheel cropped
into the corner behind the content.

### Header Icons

`SheetHeader` takes an `icon` — `ChakraIcon`, `PadmaIcon`, or
`DeulaIcon` ship with
the component, both drawn inline in `currentColor`.

### Left Sheet

`side="left"` moves the close button to the top-left, poster style,
and nudges the header below it. The default deula watermark sits
behind the content.

## API Reference

### Sheet / SheetTrigger / SheetClose / SheetOverlay / SheetPortal

Thin wrappers around Base UI's dialog parts — all Base UI props are
forwarded. Triggers take Base UI's `render` prop.

### SheetContent

| Prop              | Type                                     | Default   | Description                               |
| ----------------- | ---------------------------------------- | --------- | ----------------------------------------- |
| `side`            | `"top" \| "right" \| "bottom" \| "left"` | `"right"` | The edge the sheet slides in from.        |
| `ornament`        | `boolean`                                | `false`   | Ikat diamond strip on the bottom edge.    |
| `watermark`       | `"none" \| "deula" \| "chakra"`          | `"deula"` | Faint rekha deula behind the content.     |
| `handle`          | `boolean`                                | `false`   | Grabber bar at the top; visual only.      |
| `showCloseButton` | `boolean`                                | `true`    | Renders the built-in close button.        |
| `className`       | `string`                                 | -         | Additional classes merged onto the popup. |

### SheetHeader / SheetTitle / SheetDescription / SheetFooter / SheetOrnament

| Component       | Notes                                                                  |
| --------------- | ---------------------------------------------------------------------- |
| `SheetHeader`   | `icon` prop renders a leading icon in the accent colour.               |
| `SheetOrnament` | The Ikat strip as a standalone divider; `SheetContent` renders it too. |
