## Installation

```bash
npx shadcn@latest add https://odiaui.xyz/r/sheet.json
```

Colours come only from shadcn theme tokens, so the sheet follows your theme automatically in light and dark mode.

## Usage

```tsx
import {
  Sheet,
  SheetClose,
  SheetContent,
  SheetDescription,
  SheetFooter,
  SheetHeader,
  SheetTitle,
  SheetTrigger,
} from "@/components/ui/sheet";
```

```tsx
<Sheet>
  <SheetTrigger render={<Button variant="outline" />}>Open</SheetTrigger>
  <SheetContent side="right">
    <SheetHeader>
      <SheetTitle>Title</SheetTitle>
      <SheetDescription>Description</SheetDescription>
    </SheetHeader>
    <div className="px-4">Content</div>
    <SheetFooter>
      <SheetClose render={<Button />}>Done</SheetClose>
    </SheetFooter>
  </SheetContent>
</Sheet>
```

Base UI uses the `render` prop instead of `asChild` for triggers, closes, and other composable actions.

## API Reference

### Sheet / SheetTrigger / SheetClose / SheetOverlay / SheetPortal

Thin wrappers around Base UI dialog primitives used to build sheets. Triggers and closes accept Base UI's `render` prop.

### SheetContent

| Prop              | Type                                     | Default   | Description                                       |
| ----------------- | ---------------------------------------- | --------- | ------------------------------------------------- |
| `side`            | `"top" \| "right" \| "bottom" \| "left"` | `"right"` | Edge the sheet slides in from.                    |
| `showCloseButton` | `boolean`                                | `true`    | Renders the built-in close button.                |
| `handle`          | `boolean`                                | `false`   | Visual grabber bar (typically for bottom sheets). |
| `watermark`       | `"none" \| "deula" \| "chakra"`          | `"none"`  | Optional faint background artwork.                |
| `ornament`        | `boolean`                                | `false`   | Optional decorative strip.                        |
| `className`       | `string`                                 | -         | Additional classes merged onto the popup.         |

### SheetHeader / SheetTitle / SheetDescription / SheetFooter

Layout helpers for sheet content. `SheetHeader` supports an optional `icon` prop, and `SheetFooter` is pinned to the bottom for actions.
