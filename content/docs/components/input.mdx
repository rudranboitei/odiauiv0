## Installation

```bash
npx shadcn@latest add https://odiaui.vercel.app/r/input.json
```

The presets render inline icons drawn with `currentColor`, and the error
message uses the `FieldMessage` from the Label component — installing
the input pulls in the label automatically.

## Usage

```tsx
import { Input } from "@/components/ui/input";
```

```tsx
<Input placeholder="Enter your name..." />
```

## Examples

### Presets

The `variant` prop is a preset: `search` adds a magnifier with a tiny
Konark wheel in the lens, `email` adds a mail icon and `type="email"`,
`password` adds a lock icon with a show/hide toggle, and `file` turns
the field into a file picker.

### Addons

`addonStart` and `addonEnd` render bordered blocks before and after the
field — currency prefixes, suffixes, or URL parts. `startIcon` and
`endIcon` accept any inline icon.

### Sizes

Three sizes, `sm`, `md`, and `lg`.

### States

`invalid` marks the field and shows an alert icon. The `error` prop
renders a destructive `FieldMessage` under the field — wired with
`aria-describedby` and `aria-invalid` automatically — and marks the
field invalid too.

## API Reference

### Input

Renders a Base UI `Input`. With no icons or addons it renders as a bare
input; with any icon, addon, or the password toggle it renders as a
grouped field. With `error`, the field and message are wrapped in a
`grid` and linked with `aria-describedby`.

| Prop         | Type                                                       | Default     | Description                                                  |
| ------------ | ---------------------------------------------------------- | ----------- | ------------------------------------------------------------ |
| `variant`    | `"default" \| "search" \| "email" \| "password" \| "file"` | `"default"` | Preset that adds the matching icon and input type.           |
| `size`       | `"sm" \| "md" \| "lg"`                                     | `"md"`      | The height and text size of the field.                       |
| `startIcon`  | `React.ReactNode`                                          | -           | Inline element before the field.                             |
| `endIcon`    | `React.ReactNode`                                          | -           | Inline element after the field.                              |
| `addonStart` | `React.ReactNode`                                          | -           | Bordered block before the field, e.g. `"₹"`.                 |
| `addonEnd`   | `React.ReactNode`                                          | -           | Bordered block after the field, e.g. `".00"`.                |
| `invalid`    | `boolean`                                                  | `false`     | Marks the field invalid (`aria-invalid`) with an alert icon. |
| `error`      | `React.ReactNode`                                          | -           | Error message shown under the field; marks it invalid too.   |
| `type`       | `string`                                                   | preset      | Overrides the preset's input type.                           |
| `className`  | `string`                                                   | -           | Additional classes merged onto the field (or the group).     |

All other native input attributes are forwarded.
