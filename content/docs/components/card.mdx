## Installation

```bash
npx shadcn@latest add https://odiaui.vercel.app/r/card.json
```

Colours come only from shadcn theme tokens, so cards follow your theme
automatically in light and dark mode.

## Usage

```tsx
import {
  Card,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardTitle,
} from "@/components/ui/card";
```

```tsx
<Card>
  <CardHeader>
    <CardTitle>Title</CardTitle>
    <CardDescription>Description</CardDescription>
  </CardHeader>
  <CardContent>Content</CardContent>
  <CardFooter>Footer</CardFooter>
</Card>
```

The watermark is **opt-in**: cards are plain by default. Pass
`watermark` to add a faint **deula watermark** cropped into the
bottom-right corner, or swap in the Konark wheel or a lotus with
`watermark="chakra"` / `watermark="padma"`.

## Examples

### Size

Use `size="sm"` for a compact card — it drives all padding through the
`--card-spacing` variable.

### Spacing

The card's internal spacing is a CSS variable. Override it with the
`--spacing()` function, alone or per size:

```tsx
<Card className="[--card-spacing:--spacing(8)]">...</Card>
```

## API Reference

### Card

The outer container. A `relative isolate overflow-hidden` flex column
with the watermark layer behind the content.

| Prop        | Type                                       | Default     | Description                                       |
| ----------- | ------------------------------------------ | ----------- | ------------------------------------------------- |
| `size`      | `"default" \| "sm"`                        | `"default"` | Compact preset; sets `--card-spacing` to 4/6.     |
| `watermark` | `"none" \| "deula" \| "chakra" \| "padma"` | `"none"`    | Opt-in faint Odisha artwork in the card's corner. |
| `className` | `string`                                   | -           | Additional classes merged onto the container.     |

#### Theming

All internal spacing reads `--card-spacing` (default 6 = 24px, `sm` =
4 = 16px). Override it anywhere on or around the card:

```tsx
<Card className="[--card-spacing:--spacing(8)]">
```

Then use negative / positive spacing utilities like
`-mx-(--card-spacing)` to bleed content to the edges.

### CardHeader / CardTitle / CardDescription

The header layout (grid with an optional action column), heading, and
supporting text.

### CardAction

Aligned to the top-right of the header — badges, icon buttons, or
bookmark toggles.

### CardContent / CardFooter

Main content area and footer row.

### CardMedia

| Prop       | Type                          | Default | Description                          |
| ---------- | ----------------------------- | ------- | ------------------------------------ |
| `position` | `"top" \| "left" \| "bottom"` | `"top"` | Which card edge the media bleeds to. |

Style the image with `[&>img]:object-cover` (built in); any child
element works, not just `<img>`.

### CardOrnament

Inline SVG with an Ikat diamond pattern; `className` recolours or
insets it.
