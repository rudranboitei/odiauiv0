## Installation

```bash
npx shadcn@latest add https://odiaui.vercel.app/r/card.json
```

Colours come only from shadcn theme tokens, so cards follow your theme
automatically in light and dark mode.

## Usage

```tsx
import {
  Card,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardTitle,
} from "@/components/ui/card";
```

```tsx
<Card>
  <CardHeader>
    <CardTitle>Title</CardTitle>
    <CardDescription>Description</CardDescription>
  </CardHeader>
  <CardContent>Content</CardContent>
  <CardFooter>Footer</CardFooter>
</Card>
```

Heritage is on by default: every card carries a faint **deula
watermark** cropped into its bottom-right corner. Opt out with
`watermark="none"`, or swap in the Konark wheel or a lotus with
`watermark="chakra"` / `watermark="padma"`.

## Examples

### Media

`CardMedia` renders an image or illustration that bleeds to the card
edges — above the content by default, or beside it with
`position="left"` (wrap it and the header in a flex row), or below
with `position="bottom"`. Pair it with a `Badge` in `CardAction` for
the classic heritage-tourism look.

`CardOrnament` is a thin Ikat diamond strip — use it as a divider
under a header (add `mx-6` to keep the card's inner padding).

## API Reference

### Card

The outer container. A `relative isolate` flex column with the
watermark layer behind the content.

| Prop        | Type                                       | Default   | Description                                   |
| ----------- | ------------------------------------------ | --------- | --------------------------------------------- |
| `watermark` | `"none" \| "deula" \| "chakra" \| "padma"` | `"deula"` | Faint Odisha artwork in the card's corner.    |
| `className` | `string`                                   | -         | Additional classes merged onto the container. |

### CardHeader / CardTitle / CardDescription

The header layout (grid with an optional action column), heading, and
supporting text.

### CardAction

Aligned to the top-right of the header — badges, icon buttons, or
bookmark toggles.

### CardContent / CardFooter

Main content area and footer row.

### CardMedia

| Prop       | Type                          | Default | Description                          |
| ---------- | ----------------------------- | ------- | ------------------------------------ |
| `position` | `"top" \| "left" \| "bottom"` | `"top"` | Which card edge the media bleeds to. |

Style the image with `[&>img]:object-cover` (built in); any child
element works, not just `<img>`.

### CardOrnament

Inline SVG with an Ikat diamond pattern; `className` recolours or
insets it.
