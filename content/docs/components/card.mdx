## Installation

```bash
npx shadcn@latest add https://odiaui.vercel.app/r/card.json
```

## Usage

```tsx
import {
  Card,
  CardContent,
  CardDescription,
  CardHeader,
  CardTitle,
} from "@/components/ui/card";

export function Example() {
  return (
    <Card>
      <CardHeader>
        <CardTitle>Konark</CardTitle>
        <CardDescription>Sun Temple, Odisha</CardDescription>
      </CardHeader>
      <CardContent>Built with odiaui.</CardContent>
    </Card>
  );
}
```

## Subcomponents

- `Card` — the outer container.
- `CardHeader` — the header layout.
- `CardTitle` — the card heading.
- `CardDescription` — supporting text below the heading.
- `CardAction` — an optional action aligned to the top-right of the header.
- `CardContent` — the main content area.
- `CardFooter` — the footer layout.
