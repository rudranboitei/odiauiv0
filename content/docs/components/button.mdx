## Examples

### Variants

Use the `variant` prop to change the look of the button. Buttons are fully
rounded with a matte finish and soft layered shadows. `default` is the solid
ink action, `frame` adds a double-border heritage frame, and `secondary` uses
a soft neutral surface for quieter actions.

Filled and outline variants also render a subtle Konark temple-and-wheel
artwork behind the label. `watermark="none"` turns it off,
`watermark="deula"` keeps only the temple, and `watermark="chakra"`
only the wheel — leaving it unset keeps the stock behaviour.

### Sizes

Use the `size` prop to change the size of the button. Icon sizes render a
square button and expect a single icon as their child; `icon-full` renders it
as a circle.

## API Reference

### Button

The `Button` component is a radix `Slot`-based button element with OdiaUI
heritage styling, a variety of sizes and variants, and optional decorative
temple artwork.

| Prop        | Type                                                                                     | Default     | Description                                                                                                   |
| ----------- | ---------------------------------------------------------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------- |
| `variant`   | `"default" \| "secondary" \| "destructive" \| "outline" \| "ghost" \| "link" \| "frame"` | `"default"` | The visual style of the button.                                                                               |
| `size`      | `"sm" \| "default" \| "lg" \| "icon" \| "icon-sm" \| "icon-full"`                        | `"default"` | The size of the button. Icon sizes render a square button.                                                    |
| `loading`   | `boolean`                                                                                | `false`     | Shows a spinner, disables interaction and sets `aria-busy`.                                                   |
| `watermark` | `"auto" \| "deula" \| "chakra" \| "none"`                                                | `"auto"`    | Temple and/or wheel artwork behind the label. Auto: on for filled styles, off for ghost, link and icon sizes. |
| `asChild`   | `boolean`                                                                                | `false`     | Renders the styles on the single child element instead of a button.                                           |
| `className` | `string`                                                                                 | -           | Additional classes merged onto the button.                                                                    |

See the [shadcn/ui button documentation](https://ui.shadcn.com/docs/components/button)
for more information.
