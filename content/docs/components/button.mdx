## Examples

### Variants

Use the `variant` prop to change the look of the button. `default` is the solid
brand action, `gold` is the high-contrast inverse, and `secondary` uses a soft
neutral surface for quieter actions. The palette is intentionally monochrome to
match the OdiaUI brand, with semantic red reserved for `destructive`.

<ComponentPreview name="button-variants">
  <ButtonVariants />
</ComponentPreview>

### Sizes

Use the `size` prop to change the size of the button. Icon sizes render a
square button and expect a single icon as their child.

<ComponentPreview name="button-sizes">
  <ButtonSizes />
</ComponentPreview>

### With Icon

`ButtonChakra` adds the Konark wheel medallion to the start of a button. For
plain icons, add `data-icon="inline-start"` or `data-icon="inline-end"` so the
spacing matches the button size.

<ComponentPreview name="button-with-icon">
  <ButtonWithIcon />
</ComponentPreview>

### Medallion

`ButtonMedallion` renders the round brand badge on its own. Drop any lucide icon
inside it.

<ComponentPreview name="button-medallion">
  <ButtonMedallionDemo />
</ComponentPreview>

### Disabled

Add the `disabled` prop to fade the button into the disabled neutral state and
prevent interaction.

<ComponentPreview name="button-disabled">
  <ButtonDisabled />
</ComponentPreview>

### Loading

Render a spinning `Loader2` icon inside a disabled button to show a loading
state. The `data-icon="inline-start"` attribute keeps the spacing consistent.

### As Link

Use Base UI's `render` prop with `nativeButton={false}` to render the button
styles on an anchor element.

## API Reference

### Button

The `Button` component is a wrapper around the Base UI button element that adds
the OdiaUI heritage styling and a variety of sizes and variants.

| Prop        | Type                                                                                    | Default     | Description                                                     |
| ----------- | --------------------------------------------------------------------------------------- | ----------- | --------------------------------------------------------------- |
| `variant`   | `"default" \| "gold" \| "secondary" \| "outline" \| "ghost" \| "destructive" \| "link"` | `"default"` | The visual style of the button.                                 |
| `size`      | `"xs" \| "sm" \| "default" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"`    | `"default"` | The size of the button. Icon sizes render a square button.      |
| `disabled`  | `boolean`                                                                               | `false`     | Prevents interaction and fades the button.                      |
| `render`    | `React.ReactElement`                                                                    | -           | Replaces the rendered element, for example to render an anchor. |
| `className` | `string`                                                                                | -           | Additional classes merged onto the button.                      |

See the [Base UI documentation](https://base-ui.com/react/components/button) for
more information.
