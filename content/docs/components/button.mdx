## Installation

```bash
npx shadcn@latest add https://odiaui.xyz/r/button.json
```

### Button Kit

The button kit adds 45 ready-made button patterns on top of the base
`Button` — action buttons, state buttons, toggles, auth/social buttons,
icon buttons and layout buttons — in a single copy-paste file.

```bash
npx shadcn@latest add https://odiaui.xyz/r/button-kit.json
```

## Usage

```tsx
import { Button } from "@/components/ui/button";
```

```tsx
<Button>Click me</Button>
```

## Button Kit

One kit, six families. Every component is self-contained and built on the
base `Button`, so props like `variant`, `size` and `loading` keep working.

### Actions

Everyday verbs: add to cart (icon + quantity feedback + success tick),
buy now (high emphasis, full width on mobile), save (loading, then
"Saved"), submit (disabled until the form is valid — pass `valid`),
cancel / back, delete (destructive with a confirm step — click once,
then "Are you sure?"), edit, duplicate, share, download, upload, and
refresh with a spinning icon.

## API Reference

### Button

The `Button` component is a radix `Slot`-based button element with a
clean token-driven style, a variety of sizes and variants, and a built-in
loading state.

| Prop        | Type                                                                                     | Default     | Description                                                         |
| ----------- | ---------------------------------------------------------------------------------------- | ----------- | ------------------------------------------------------------------- |
| `variant`   | `"default" \| "secondary" \| "destructive" \| "outline" \| "ghost" \| "link" \| "frame"` | `"default"` | The visual style of the button.                                     |
| `size`      | `"sm" \| "default" \| "lg" \| "icon" \| "icon-sm" \| "icon-full"`                        | `"default"` | The size of the button. Icon sizes render a square button.          |
| `loading`   | `boolean`                                                                                | `false`     | Shows a spinner, disables interaction and sets `aria-busy`.         |
| `asChild`   | `boolean`                                                                                | `false`     | Renders the styles on the single child element instead of a button. |
| `className` | `string`                                                                                 | -           | Additional classes merged onto the button.                          |

### Button Kit

Every kit component forwards all base `Button` props (`variant`, `size`,
`className`, …) unless noted. The notable additions:

| Component              | Prop                                 | Description                                                                  |
| ---------------------- | ------------------------------------ | ---------------------------------------------------------------------------- |
| `SubmitButton`         | `valid?: boolean`                    | Disabled until the form is valid.                                            |
| `DeleteConfirmButton`  | `onDelete?: () => void`              | First click arms ("Are you sure?"), second click confirms.                   |
| `ErrorRetryButton`     | `onRun?: () => Promise<void>`        | Rejecting the promise triggers the shake + "Try again".                      |
| `CountdownButton`      | `duration?: number`                  | Seconds to count down after firing `onResend`. Defaults to `30`.             |
| `HoldToConfirmButton`  | `onConfirm?: () => void`             | Fires after holding for ~1.2s.                                               |
| `LikeButton`           | `count?: number`                     | Starting like count.                                                         |
| `FollowButton`         | `onFollow?: () => void`              | Hover a "Following" button to reveal "Unfollow".                             |
| `CopyLinkButton`       | `link: string`                       | Text to copy; shows "Copied!" for 2s. `copiedLabel` customises the feedback. |
| `IconButton`           | `label: string`                      | Used for the tooltip and the accessible name.                                |
| `FabButton`            | `label?: string`                     | Accessible name; position it yourself with `className="fixed …"`.            |
| `ExpandCollapseButton` | `open?`, `onOpenChange?`             | Controlled or uncontrolled chevron state.                                    |
| `Pagination`           | `page`, `totalPages`, `onPageChange` | Current page, page count and change handler.                                 |
| `SegmentedControl`     | `options`, `value`, `onValueChange`  | Single-choice pill switcher.                                                 |
| `SplitButton`          | `items`, `onPrimary?`                | Dropdown entries for the arrow segment.                                      |
| `BadgeButton`          | `count?: number`                     | Notification count shown in the pill.                                        |
| `ShortcutButton`       | `shortcut?: string`                  | Keyboard hint text. Defaults to `⌘K`.                                        |

See the [shadcn/ui button documentation](https://ui.shadcn.com/docs/components/button)
for more information.
