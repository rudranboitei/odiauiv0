## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"default" \| "secondary" \| "destructive" \| "outline" \| "ghost" \| "link" \| "frame"` | `"default"` | Visual style of the button. |
| `size` | `"sm" \| "default" \| "lg" \| "icon" \| "icon-sm" \| "icon-full"` | `"default"` | Size of the button. |
| `loading` | `boolean` | `false` | Shows a spinner and blocks clicks while `true`. |
| `asChild` | `boolean` | `false` | Merge props onto the child element (Radix Slot). |
