## Examples

### Motifs

When checked, the thumb carries a cultural icon from the Badge
component's set, drawn inline in `currentColor` — `chakra` by
default. Pass any motif name, or `motif="none"` for the plain stock
thumb. The motif is hidden on the small size, where the thumb is too
tiny for artwork.

<ComponentPreview name="switch-motifs">
  <SwitchMotifs />
</ComponentPreview>

### Sizes

Two sizes: `default` and `sm`. Pair with the Label component for
clickable labels.

<ComponentPreview name="switch-sizes">
  <SwitchSizes />
</ComponentPreview>

### States

The `disabled` prop fades the switch and blocks interaction. The track
uses theme tokens — `bg-primary` when checked, `bg-input` when not —
so it follows light and dark mode automatically.

## API Reference

### Switch

Wraps Base UI's switch root. The thumb translates across the track on
check, and the invisible `after` hit area extends the touch target.

| Prop        | Type                      | Default     | Description                              |
| ----------- | ------------------------- | ----------- | ---------------------------------------- |
| `size`      | `"sm" \| "default"`       | `"default"` | The size of the switch.                  |
| `motif`     | `BadgeIconName \| "none"` | `"chakra"`  | Cultural icon in the thumb when checked. |
| `checked`   | `boolean`                 | -           | Controlled checked state.                |
| `className` | `string`                  | -           | Additional classes merged onto the root. |

All other Base UI switch props (`onCheckedChange`, `disabled`, `required`, and more) are forwarded.
