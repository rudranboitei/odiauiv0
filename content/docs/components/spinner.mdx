```bash
npx shadcn@latest add https://odiaui.vercel.app/r/spinner.json
```

## Usage

```tsx
import { Spinner } from "@/components/ui/spinner";
```

```tsx
<Spinner />
```

## Examples

### Glyphs

The `variant` prop picks the animation: `chakra` (Konark wheel, turns
slowly), `deula` (temple tower with flag, breathes), `padma` (lotus,
opens and closes), `dots` (three dots pulsing in sequence), `ring`
(track with a turning arc), and `pulse` (ring with a glowing halo). The
default is `chakra`.

Five sizes, `xs` through `xl`.

### Labels

Pass a `label` to render the spinner with text beside it, wrapped in a
`role="status"` so screen readers announce it. `labelPosition="bottom"`
stacks the text underneath.

<ComponentPreview name="spinner-labels">
  <SpinnerLabels />
</ComponentPreview>

### Colors

The spinner inherits the surrounding text colour by default (`current`),
so it works inside Button, Badge, and alerts. The `color` prop maps to
shadcn tokens; `success` and `warning` use the emerald and amber scales.

<ComponentPreview name="spinner-colors">

</ComponentPreview>

### In Context

Use it inline in a Button while an action runs, and `disabled` fades it
and stops the motion.

## API Reference

### Spinner

The `Spinner` component renders an inline `svg` with `role="status"` and
`aria-label="Loading"`. All glyphs are drawn with `currentColor`, so
light and dark mode follow the theme automatically.

| Prop            | Type                                                                           | Default     | Description                                             |
| --------------- | ------------------------------------------------------------------------------ | ----------- | ------------------------------------------------------- |
| `variant`       | `"chakra" \| "deula" \| "padma" \| "dots" \| "ring" \| "pulse"`                | `"chakra"`  | The animated glyph.                                     |
| `size`          | `"xs" \| "sm" \| "md" \| "lg" \| "xl"`                                         | `"sm"`      | The rendered size of the spinner.                       |
| `color`         | `"current" \| "primary" \| "muted" \| "destructive" \| "success" \| "warning"` | `"current"` | Text colour the glyph inherits; `current` is inherited. |
| `label`         | `React.ReactNode`                                                              | -           | Text shown beside (or under) the spinner.               |
| `labelPosition` | `"right" \| "bottom"`                                                          | `"right"`   | Placement of the label.                                 |
| `disabled`      | `boolean`                                                                      | `false`     | Faded and still.                                        |
| `className`     | `string`                                                                       | -           | Additional classes merged onto the spinner.             |
