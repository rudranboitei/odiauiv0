## Installation

```bash
npx shadcn@latest add https://odiaui.vercel.app/r/alert.json
```

Each variant shows a cultural motif from the Badge component's icon
set, drawn inline in `currentColor` — installing the alert pulls in
the Badge automatically.

## Usage

```tsx
import { Alert, AlertDescription, AlertTitle } from "@/components/ui/alert";
```

```tsx
<Alert>
  <AlertTitle>Heads up!</AlertTitle>
  <AlertDescription>You can add components to your app.</AlertDescription>
</Alert>
```

## Examples

### Variants

Five variants on theme tokens. Each carries its own cultural motif by
default — `chakra` for default, `padma` for info, `bana` for success,
`ikat` for warning, and `jagannath` for destructive — coloured by the
variant.

<ComponentPreview name="alert-variants">
  <AlertVariants />
</ComponentPreview>

### Ornament

The `ornament` prop adds an engraved inner hairline frame, like the
border of a pattachitra panel.

<ComponentPreview name="alert-ornament">
  <AlertOrnament />
</ComponentPreview>

### Motifs

Pass `motif` to choose any of the eight cultural icons — `chakra`,
`deula`, `odissi`, `ikat`, `jagannath`, `pattachitra`, `padma`, or
`bana` — regardless of variant.

<ComponentPreview name="alert-motifs">
  <AlertMotifs />
</ComponentPreview>

### With an Action

`AlertAction` positions a button in the top-right corner, with the
description wrapping around it.

<ComponentPreview name="alert-action">
  <AlertActionDemo />
</ComponentPreview>

### Custom Icon

Pass an `<svg>` as a direct child to bring your own artwork — the
automatic motif steps aside.

```tsx
<Alert>
  <SomeIcon />
  <AlertTitle>Custom artwork</AlertTitle>
</Alert>
```

## API Reference

### Alert

Renders a `div` with `role="alert"`. The motif icons are the Badge
component's cultural icons, reused unmodified, so they stay in theme
via `currentColor`.

| Prop        | Type                                                                                             | Default         | Description                               |
| ----------- | ------------------------------------------------------------------------------------------------ | --------------- | ----------------------------------------- |
| `variant`   | `"default" \| "info" \| "destructive" \| "success" \| "warning"`                                 | `"default"`     | The colour style and default motif.       |
| `motif`     | `"chakra" \| "deula" \| "odissi" \| "ikat" \| "jagannath" \| "pattachitra" \| "padma" \| "bana"` | variant default | Cultural icon shown beside the content.   |
| `ornament`  | `boolean`                                                                                        | `false`         | Engraved inner hairline frame.            |
| `className` | `string`                                                                                         | -               | Additional classes merged onto the alert. |

### AlertTitle / AlertDescription / AlertAction

| Component          | Element | Notes                                                         |
| ------------------ | ------- | ------------------------------------------------------------- |
| `AlertTitle`       | `div`   | Bold heading; shifts right when an icon is present.           |
| `AlertDescription` | `div`   | Muted supporting text; destructive tints it.                  |
| `AlertAction`      | `div`   | Absolutely positioned top-right; reserves space with `pr-18`. |
