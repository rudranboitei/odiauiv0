## Installation

```bash
npx shadcn@latest add https://odiaui.xyz/r/alert.json
```

The install adds `components/ui/alert.tsx` — self-contained, with all
colours coming from your theme tokens and the Tailwind scale, so it
follows light and dark mode automatically.

## Usage

```tsx
import {
  Alert,
  AlertAction,
  AlertDescription,
  AlertTitle,
} from "@/components/ui/alert";
```

```tsx
<Alert variant="info" icon={<HourglassIcon />} status="Pending">
  <AlertTitle>Processing Request</AlertTitle>
  <AlertDescription>Your data is being processed.</AlertDescription>
</Alert>
```

A destructive alert with a status pill summarising everything that

### With actions

`AlertAction` renders a row below the text — a primary button plus a
plain dismiss, payment failures, expiring sessions and unverified
emails each carry their own next step.

<ComponentPreview name="alert-actions">
  <AlertActions />
</ComponentPreview>

```tsx

  <AlertAction>

    <Button size="sm" variant="ghost">
      Dismiss
    </Button>
  </AlertAction>
</Alert>
```

## API Reference

### Alert

| Prop        | Type                                                                            | Default     | Description                                                        |
| ----------- | ------------------------------------------------------------------------------- | ----------- | ------------------------------------------------------------------ |
| `variant`   | `"default" \| "info" \| "success" \| "important" \| "warning" \| "destructive"` | `"default"` | Semantic colour of the container, icon tile and status pill.       |
| `icon`      | `React.ReactNode`                                                               | -           | Leading icon — lucide icon, inline `<svg>` or any node, in a tile. |
| `status`    | `React.ReactNode`                                                               | -           | Small pill floating on the top edge (text or any node).            |
| `className` | `string`                                                                        | -           | Additional classes merged onto the container.                      |

A raw `<svg>` child also works as the icon. `role="alert"` is set for
screen readers.

### AlertTitle

| Prop        | Type     | Default | Description                               |
| ----------- | -------- | ------- | ----------------------------------------- |
| `className` | `string` | -       | Additional classes merged onto the title. |

### AlertDescription

| Prop        | Type     | Default | Description                                     |
| ----------- | -------- | ------- | ----------------------------------------------- |
| `className` | `string` | -       | Additional classes merged onto the description. |

### AlertAction

A row below the title and description — drop one or more `Button`s in
(primary + ghost dismiss is the common pattern).

| Prop        | Type     | Default | Description                                |
| ----------- | -------- | ------- | ------------------------------------------ |
| `className` | `string` | -       | Additional classes merged onto the action. |
