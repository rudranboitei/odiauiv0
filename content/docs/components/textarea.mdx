## Installation

```bash
npx shadcn@latest add https://odiaui.xyz/r/textarea.json
```

The error message uses the `FieldMessage` from the Label component —
installing the textarea pulls in the label automatically.

## Usage

```tsx
import { Textarea } from "@/components/ui/textarea";
```

```tsx
<Textarea placeholder="Share your thoughts..." />
```

## Examples

### Resize

The `resize` prop controls which way the corner handle can drag:
`vertical` (the default), `both`, or `none` to lock the height.

<ComponentPreview name="textarea-variants">
  <TextareaVariants />
</ComponentPreview>

### Character Count

`showCount` with `maxLength` renders a live `n / max` counter beside the
message row, in tabular numerals so the digits don't shift as you type.

<ComponentPreview name="textarea-count">
  <TextareaCount />
</ComponentPreview>

### States

`invalid` marks the field. The `error` prop renders a destructive
`FieldMessage` under the field — wired with `aria-describedby` and
`aria-invalid` automatically — and marks the field invalid too.

## API Reference

### Textarea

Renders a native `textarea` linked to its error message with
`aria-describedby`. The counter reads a controlled `value` directly, or
tracks its own length when uncontrolled.

| Prop        | Type                             | Default      | Description                                                |
| ----------- | -------------------------------- | ------------ | ---------------------------------------------------------- |
| `resize`    | `"none" \| "vertical" \| "both"` | `"vertical"` | Which way the corner handle can drag.                      |
| `invalid`   | `boolean`                        | `false`      | Marks the field invalid (`aria-invalid`).                  |
| `error`     | `React.ReactNode`                | -            | Error message shown under the field; marks it invalid too. |
| `showCount` | `boolean`                        | `false`      | Live `n / max` counter; needs `maxLength`.                 |
| `maxLength` | `number`                         | -            | Maximum character count, enforced natively by the browser. |
| `className` | `string`                         | -            | Additional classes merged onto the textarea.               |

All other native textarea attributes (`value`, `defaultValue`,
`onChange`, `id`, and more) are forwarded.
