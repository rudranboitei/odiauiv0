## Installation

```bash
npx shadcn@latest add https://odiaui.vercel.app/r/label.json
```

## Usage

```tsx
import { Label, FieldMessage } from "@/components/ui/label";
```

```tsx
<Label htmlFor="email" required>
  Email
</Label>
```

## Examples

### States

The `required` prop adds a red asterisk, `optional` adds a small
"Optional" pill, `invalid` turns the label destructive, and `disabled`
dims it to match a disabled field.

<ComponentPreview name="label-variants">
  <LabelVariants />
</ComponentPreview>

### Helper and Error Text

`FieldMessage` renders helper text below a field. With the `error` prop
it turns destructive, adds a leading alert icon, and sets
`role="alert"` so screen readers announce it.

<ComponentPreview name="label-messages">
  <LabelMessages />
</ComponentPreview>

### With a Field

`Label` and `FieldMessage` wrap any input — connect them with `htmlFor`
and the input's `id`. `aria-invalid` on the input and `invalid` on the
label share the destructive style.

## API Reference

### Label

| Prop        | Type      | Default | Description                                             |
| ----------- | --------- | ------- | ------------------------------------------------------- |
| `required`  | `boolean` | `false` | Adds the red asterisk. Set `required` on the field too. |
| `optional`  | `boolean` | `false` | Adds a small "Optional" pill.                           |
| `invalid`   | `boolean` | `false` | Turns the label destructive.                            |
| `disabled`  | `boolean` | `false` | Dims the label to match a disabled field.               |
| `htmlFor`   | `string`  | -       | The `id` of the field the label belongs to.             |
| `className` | `string`  | -       | Additional classes merged onto the label.               |

### FieldMessage

| Prop        | Type      | Default | Description                                                        |
| ----------- | --------- | ------- | ------------------------------------------------------------------ |
| `error`     | `boolean` | `false` | Destructive colour with a leading alert icon, sets `role="alert"`. |
| `className` | `string`  | -       | Additional classes merged onto the message.                        |

Both components also accept every native attribute of their element
(`label` and `p` respectively).
