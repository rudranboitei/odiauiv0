## Installation

```bash
npx shadcn@latest add https://odiaui.vercel.app/r/avatar.json
```

Every Odia addition is optional — with no extra props the avatar renders
exactly like the stock Base UI avatar.

## Usage

```tsx
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar";
```

```tsx
<Avatar>
  <AvatarImage src="..." alt="Portrait" />
  <AvatarFallback>RK</AvatarFallback>
</Avatar>
```

## Examples

### Heritage Frames

The `frame` prop draws artwork around the portrait, between the image
circle and the outer edge: `chakra` (Konark wheel rim with a bead
garland), `padma` (radiating lotus petals), `deula` (Kalinga spire with
a kalasha finial), `ikat` (Sambalpuri diamond band), and `pattachitra`
(rope-style painting border).

### Sizes

Four sizes: `sm`, `default`, `lg`, and `xl`. Frames and badges scale
with the avatar automatically.

### Badges

`AvatarBadge` sits at the bottom-right. The `chakra` and `padma`
variants render a built-in heritage icon tinted with the accent
colour; pass children for a plain count dot.

<ComponentPreview name="avatar-badges">
  <AvatarBadges />
</ComponentPreview>

### Accents

Heritage artwork and `tone="heritage"` fallbacks take their colour from
the `accent` prop, mapped to shadcn tokens so light and dark mode
follow the theme automatically: `bronze` → primary, `terracotta` →
destructive, and `gold` → muted-foreground. Override anywhere with
`className="text-primary"` (or any token colour).

### Groups

`AvatarGroup` stacks avatars, and `AvatarGroupCount` closes the row
with a "+n" pill sized to match.

## API Reference

### Avatar

Wraps Base UI's avatar root. The frame artwork is an inline SVG drawn
with shadcn tokens, so it themes with light and dark mode
automatically.

| Prop        | Type                                                                  | Default     | Description                                              |
| ----------- | --------------------------------------------------------------------- | ----------- | -------------------------------------------------------- |
| `size`      | `"sm" \| "default" \| "lg" \| "xl"`                                   | `"default"` | The rendered size of the avatar.                         |
| `frame`     | `"none" \| "chakra" \| "padma" \| "deula" \| "ikat" \| "pattachitra"` | `"none"`    | Heritage frame drawn around the portrait.                |
| `accent`    | `"bronze" \| "terracotta" \| "gold"`                                  | `"bronze"`  | Token colour: primary, destructive, or muted-foreground. |
| `className` | `string`                                                              | -           | Additional classes merged onto the root.                 |

### AvatarImage / AvatarFallback / AvatarBadge

| Component          | Notes                                                                         |
| ------------------ | ----------------------------------------------------------------------------- |
| `AvatarImage`      | Base UI image; falls back to initials on load failure.                        |
| `AvatarFallback`   | `tone="heritage"` tints the initials with the avatar's accent colour.         |
| `AvatarBadge`      | `variant="chakra"` or `"padma"` renders a heritage icon in the accent colour. |
| `AvatarGroup`      | Negative-margin stack with background rings.                                  |
| `AvatarGroupCount` | "+n" pill; sizes itself to match neighbouring avatars.                        |
