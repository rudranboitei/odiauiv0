## Installation

```bash
npx shadcn@latest add https://odiaui.vercel.app/r/badge.json
```

## Usage

```tsx
import { Badge } from "@/components/ui/badge";

export function Example() {
  return <Badge variant="secondary">Odisha</Badge>;
}
```

## Variants

```tsx
<Badge>Default</Badge>
<Badge variant="secondary">Secondary</Badge>
<Badge variant="outline">Outline</Badge>
<Badge variant="destructive">Destructive</Badge>
```

## Props

- `variant` — `default`, `secondary`, `outline`, or `destructive`.
- `asChild` — render the badge styles on a child element.
- `className` — additional classes merged with the default styles.
