## Installation

```bash
npx shadcn@latest add https://odiaui.vercel.app/r/badge.json
```

## Usage

```tsx
import { Badge } from "@/components/ui/badge";
```

```tsx
<Badge icon="chakra">Chakra</Badge>
```

## Examples

### Cultural Icons

The badge draws one of eight heritage motifs inline in `currentColor` —
`chakra` (Konark wheel), `deula` (temple tower with flag), `odissi`
(dancer in tribhangi), `ikat`, `jagannath`, `pattachitra`, `padma`
(lotus), and `bana` (diamond rosette). Pair them with any variant.

<ComponentPreview name="badge-icons">

</ComponentPreview>

### Variants

`default`, `secondary`, `outline`, `ghost`, `link`, and `destructive` use
the shadcn tokens. `success` and `warning` have no shadcn token, so they
use the Tailwind emerald and amber scales with dark-mode pairs. The `dot`
prop adds a leading status dot in the badge colour.

### Sizes

Five sizes, `xs` through `xl`. Pass an `icon` with no label and the badge
becomes square and icon-only.

### Status

`loading` replaces the icon or dot with a dotted spinner, and `disabled`
dims the badge.

### As a Link

Render the badge as an anchor with the `render` prop:

```tsx
import Link from "next/link";

<Badge render={<Link href="/components" />} variant="secondary">
  Components
</Badge>;
```

## API Reference

### Badge

The `Badge` component renders a `span` by default and uses Base UI's
`useRender`, so it can render as any element through the `render` prop.

| Prop        | Type                                                                                                    | Default     | Description                                                        |
| ----------- | ------------------------------------------------------------------------------------------------------- | ----------- | ------------------------------------------------------------------ |
| `variant`   | `"default" \| "secondary" \| "destructive" \| "outline" \| "ghost" \| "link" \| "success" \| "warning"` | `"default"` | The colour style of the badge.                                     |
| `size`      | `"xs" \| "sm" \| "md" \| "lg" \| "xl"`                                                                  | `"sm"`      | The height, text size, and icon size of the badge.                 |
| `icon`      | `"chakra" \| "deula" \| "odissi" \| "ikat" \| "jagannath" \| "pattachitra" \| "padma" \| "bana"`        | -           | Cultural icon shown before the label. Icon-only if no label.       |
| `dot`       | `boolean`                                                                                               | `false`     | Leading status dot in the badge colour.                            |
| `loading`   | `boolean`                                                                                               | `false`     | Dotted spinner in place of the icon or dot, sets `aria-busy`.      |
| `disabled`  | `boolean`                                                                                               | `false`     | Dims the badge and blocks pointer events.                          |
| `render`    | `React.ReactElement`                                                                                    | -           | Base UI render prop — render the badge as a link or other element. |
| `className` | `string`                                                                                                | -           | Additional classes merged onto the badge.                          |

### BadgeIcon

Standalone access to the cultural icons:

```tsx
import { BadgeIcon } from "@/components/ui/badge";

<BadgeIcon name="chakra" className="size-6" />;
```
