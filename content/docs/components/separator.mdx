## API Reference

### Separator

The `Separator` component is a Base UI separator element with clean OdiaUI styling. Styles and patterns are drawn inline with theme tokens, so they follow light and dark mode automatically.

| Prop          | Type                                                             | Default        | Description                                         |
| ------------- | ---------------------------------------------------------------- | -------------- | --------------------------------------------------- |
| `variant`     | `"plain" \| "default" \| "dashed" \| "double" \| "diamond" \| "rekha"` | `"default"`    | The visual style of the separator.                  |
| `ornament`    | `"diamond" \| null`                                              | variant's own  | Overrides the centre ornament on ornament variants. |
| `label`       | `React.ReactNode`                                                | -              | Text shown under the ornament (horizontal only).    |
| `orientation` | `"horizontal" \| "vertical"`                                     | `"horizontal"` | The direction of the separator.                     |
| `children`    | `React.ReactNode`                                                | -              | Extra content rendered inside the separator.        |
| `className`   | `string`                                                         | -              | Additional classes merged onto the separator.       |
