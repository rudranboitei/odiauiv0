## Installation

```bash
npx shadcn@latest add https://odiaui.vercel.app/r/accordion.json
```

The install adds `components/ui/accordion.tsx` and pulls in the Badge
component, whose cultural icons the triggers reuse. All colours come
from your theme tokens and `currentColor`, so the accordion follows
light and dark mode automatically.

## Usage

```tsx
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@/components/ui/accordion";

export function Example() {
  return (
    <Accordion defaultValue={["item-1"]}>
      <AccordionItem value="item-1">
        <AccordionTrigger>Is it accessible?</AccordionTrigger>
        <AccordionContent>
          Yes. It adheres to the WAI-ARIA design pattern.
        </AccordionContent>
      </AccordionItem>
    </Accordion>
  );
}
```

## Examples

### Indicators

The inline icon before the content flips over when the panel opens:
`chevron` (the default), `chakra` (a Konark wheel), or `plus`. All are
drawn inline in `currentColor`.

### Cultural Motifs

The `motif` prop puts one of the Badge component's cultural icons in a
coin medallion beside the heading — `chakra`, `deula`, `odissi`, `ikat`,
`jagannath`, `pattachitra`, `padma`, or `bana`. The icons are drawn
inline in `currentColor`, so they pick up your theme colours and light
up when their row opens.

```tsx
<AccordionTrigger motif="jagannath">
  Pattachitra Art: Scrolls of Heritage
</AccordionTrigger>
```

### Custom Icons

Pass any React node to the `icon` prop to override the motif with your
own artwork — an inline `<svg>`, a lucide icon, or an `<img>`.

`variant="card"` turns each item into its own borderless, rounded card
instead of hairline-divided rows. `size` is available in `sm`, `md`,
and `lg` on the root.

## API Reference

### Accordion

Wraps Base UI's accordion root and provides the `variant` and `size` to
every item, trigger, and panel through context.

| Prop            | Type                                  | Default       | Description                                        |
| --------------- | ------------------------------------- | ------------- | -------------------------------------------------- |
| `variant`       | `"separated" \| "card"`               | `"separated"` | Hairline-divided rows or individual rounded cards. |
| `size`          | `"sm" \| "md" \| "lg"`                | `"md"`        | Trigger height and panel density.                  |
| `multiple`      | `boolean`                             | `false`       | Allow several items to stay open at once.          |
| `defaultValue`  | `unknown[]`                           | -             | Initially open item values.                        |
| `value`         | `unknown[]`                           | -             | Controlled open item values.                       |
| `onValueChange` | `(value: unknown[], details) => void` | -             | Called when the open set changes.                  |
| `disabled`      | `boolean`                             | `false`       | Disables every item.                               |
| `className`     | `string`                              | -             | Additional classes merged onto the root.           |

### AccordionItem

| Prop        | Type      | Default | Description                     |
| ----------- | --------- | ------- | ------------------------------- |
| `value`     | `unknown` | auto    | The unique value of the item.   |
| `disabled`  | `boolean` | `false` | Disables the item.              |
| `className` | `string`  | -       | Additional classes on the item. |

### AccordionTrigger

| Prop        | Type                                                                                             | Default     | Description                                       |
| ----------- | ------------------------------------------------------------------------------------------------ | ----------- | ------------------------------------------------- |
| `motif`     | `"chakra" \| "deula" \| "odissi" \| "ikat" \| "jagannath" \| "pattachitra" \| "padma" \| "bana"` | -           | Cultural icon from Badge in a coin medallion.     |
| `icon`      | `ReactNode`                                                                                      | -           | Custom medallion artwork; overrides `motif`.      |
| `indicator` | `"chevron" \| "chakra" \| "plus"`                                                                | `"chevron"` | Inline icon that flips over when the panel opens. |
| `className` | `string`                                                                                         | -           | Additional classes on the trigger.                |

### AccordionContent

The panel animates its height with Base UI's panel transition and
respects `prefers-reduced-motion`.

| Prop        | Type     | Default | Description                      |
| ----------- | -------- | ------- | -------------------------------- |
| `className` | `string` | -       | Additional classes on the panel. |

See the [Base UI documentation](https://base-ui.com/react/components/accordion) for more information.
