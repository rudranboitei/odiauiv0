## Installation

```bash
npx shadcn@latest add https://odiaui.xyz/r/accordion.json
```

The install adds `components/ui/accordion.tsx` — self-contained, with all
colours coming from your theme tokens and `currentColor`, so it follows
light and dark mode automatically.

## Usage

```tsx
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@/components/ui/accordion";

export function Example() {
  return (
    <Accordion defaultValue={["item-1"]}>
      <AccordionItem value="item-1">
        <AccordionTrigger>Is it accessible?</AccordionTrigger>
        <AccordionContent>
          Yes. It adheres to the WAI-ARIA design pattern.
        </AccordionContent>
      </AccordionItem>
    </Accordion>
  );
}
```

## Examples

### Single / multiple open

By default only one panel stays open — pass the `multiple` prop to let
several expand at once.

<ComponentPreview name="accordion-modes">
  <AccordionModes />
</ComponentPreview>

```tsx
<Accordion variant="bordered">…</Accordion>
<Accordion multiple>…</Accordion>
```

### Indicators

Pick the trailing indicator with the `indicator` prop: `chevron` (the
default, rotates 180°), a morphing `plus` that becomes a minus,
`numbered` (leading step numbers via the item's `number` prop), or
`none`. Pass any node to `icon` for a leading icon chip.

<ComponentPreview name="accordion-indicators">
  <AccordionIndicators />
</ComponentPreview>

```tsx
<AccordionTrigger indicator="plus">…</AccordionTrigger>
<AccordionTrigger indicator="numbered">…</AccordionTrigger>
<AccordionItem number="01" …>
<AccordionTrigger icon={<WalletIcon />}>…</AccordionTrigger>
```

### Bordered, flush, card

Four style families via the `variant` prop: `flush` (hairline dividers,
the default), `bordered` (one rounded panel with internal dividers),
`card` (each row is its own bordered card), and `timeline` (rail with
dots — see below).

<ComponentPreview name="accordion-styles">
  <AccordionStyles />
</ComponentPreview>

```tsx
<Accordion variant="flush">…</Accordion>
<Accordion variant="bordered">…</Accordion>
<Accordion variant="card">…</Accordion>
```

### Nested accordion

Accordions compose — drop an inner (flush) accordion into any
`AccordionContent`.

<ComponentPreview name="accordion-nested">
  <AccordionNested />
</ComponentPreview>

```tsx
<Accordion>
  <AccordionItem value="support">
    <AccordionTrigger>Support & policies</AccordionTrigger>
    <AccordionContent>
      <Accordion>
        <AccordionItem value="returns">
          <AccordionTrigger indicator="plus">Return policy</AccordionTrigger>
          <AccordionContent>…</AccordionContent>
        </AccordionItem>
      </Accordion>
    </AccordionContent>
  </AccordionItem>
</Accordion>
```

### Expand all / Collapse all

Control the accordion with `value` + `onValueChange` and set the array
yourself — a button that sets every key expands all, an empty array
collapses all.

### Timeline accordion

`variant="timeline"` puts a dot on each trigger and a rail down the left
— pairs well with the `plus` indicator for changelogs and milestones.

<ComponentPreview name="accordion-timeline">
  <AccordionTimeline />
</ComponentPreview>

```tsx
<Accordion variant="timeline">
  <AccordionItem value="2024">
    <AccordionTrigger indicator="plus">Milestone</AccordionTrigger>
    <AccordionContent>…</AccordionContent>
  </AccordionItem>
</Accordion>
```

## API Reference

### Accordion

Wraps Base UI's accordion root. Every row inherits the `variant` and
`size` through context.

| Prop                      | Type                                            | Default   | Description                                                 |
| ------------------------- | ----------------------------------------------- | --------- | ----------------------------------------------------------- |
| `variant`                 | `"flush" \| "bordered" \| "card" \| "timeline"` | `"flush"` | Style family of the rows.                                   |
| `size`                    | `"sm" \| "md" \| "lg"`                          | `"md"`    | Trigger and panel density.                                  |
| `multiple`                | `boolean`                                       | `false`   | Allow several open panels at once.                          |
| `value` / `onValueChange` | `string[]` / `(value: string[]) => void`        | -         | Controlled open panels — use for expand-all / collapse-all. |
| `defaultValue`            | `string[]`                                      | -         | Initially open panels (uncontrolled).                       |
| `className`               | `string`                                        | -         | Additional classes merged onto the container.               |

### AccordionItem

| Prop     | Type     | Default | Description                                                 |
| -------- | -------- | ------- | ----------------------------------------------------------- |
| `value`  | `string` | -       | Unique key for the row; used in `value` / `defaultValue`.   |
| `number` | `string` | -       | Step label shown by the `numbered` indicator (e.g. `"01"`). |

### AccordionTrigger

| Prop        | Type                                          | Default     | Description                                                   |
| ----------- | --------------------------------------------- | ----------- | ------------------------------------------------------------- |
| `indicator` | `"chevron" \| "plus" \| "numbered" \| "none"` | `"chevron"` | Trailing indicator; `plus` morphs into a minus when open.     |
| `icon`      | `React.ReactNode`                             | -           | Leading chip — inline icon, lucide icon or `<img>` thumbnail. |
| `className` | `string`                                      | -           | Additional classes merged onto the trigger.                   |

### AccordionContent

Animated panel (`height` + `opacity`, respects `prefers-reduced-motion`).
Accepts any children — including a nested accordion or media.
