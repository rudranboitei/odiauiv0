## Installation

```bash
npx shadcn@latest add https://odiaui.vercel.app/r/accordion.json
```

The install adds `components/ui/accordion.tsx` and the optional medallion icons
in `components/ui/odia-icons.tsx`.

This component targets Tailwind CSS 4 and a shadcn/ui project. The heritage
palette is intentionally fixed; pass `className` to override individual styles.
Typography is inherited from your project, so the accordion matches the rest of
your UI.

## Usage

```tsx
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@/components/ui/accordion";

export function Example() {
  return (
    <Accordion defaultValue={["item-1"]}>
      <AccordionItem value="item-1">
        <AccordionTrigger>Is it accessible?</AccordionTrigger>
        <AccordionContent>
          Yes. It adheres to the WAI-ARIA design pattern.
        </AccordionContent>
      </AccordionItem>
      <AccordionItem value="item-2">
        <AccordionTrigger>Can I open more than one?</AccordionTrigger>
        <AccordionContent>
          Yes. Add the `multiple` prop to the root to allow several items to
          stay open at once.
        </AccordionContent>
      </AccordionItem>
    </Accordion>
  );
}
```

## Icons

Pass any React node to the `icon` prop to render it inside the round indigo
medallion. The included `odia-icons.tsx` exports four ready-made SVG icons:
`KonarkWheelIcon`, `JagannathIcon`, `SambalpuriIcon`, and `OdissiDancerIcon`.

```tsx
import { KonarkWheelIcon } from "@/components/ui/odia-icons";

<AccordionTrigger icon={<KonarkWheelIcon />}>
  Konark Sun Temple
</AccordionTrigger>;
```

The `icon` prop is optional. Omit it for a compact accordion without the
medallion, as shown in the [Without icons](#without-icons) example.

## Composition

Use the following composition to build an accordion:

```txt
Accordion
├── AccordionItem
│   ├── AccordionTrigger
│   └── AccordionContent
└── AccordionItem
    ├── AccordionTrigger
    └── AccordionContent
```

## API Reference

### Accordion

| Prop            | Type                                  | Default |
| --------------- | ------------------------------------- | ------- |
| `multiple`      | `boolean`                             | `false` |
| `defaultValue`  | `unknown[]`                           | -       |
| `value`         | `unknown[]`                           | -       |
| `onValueChange` | `(value: unknown[], details) => void` | -       |
| `keepMounted`   | `boolean`                             | `false` |
| `disabled`      | `boolean`                             | `false` |
| `className`     | `string`                              | -       |

### AccordionItem

| Prop           | Type                      | Default |
| -------------- | ------------------------- | ------- |
| `value`        | `unknown`                 | auto    |
| `disabled`     | `boolean`                 | `false` |
| `onOpenChange` | `(open: boolean) => void` | -       |
| `className`    | `string`                  | -       |

### AccordionTrigger

| Prop        | Type        | Default |
| ----------- | ----------- | ------- |
| `icon`      | `ReactNode` | -       |
| `className` | `string`    | -       |

### AccordionContent

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

See the [Base UI documentation](https://base-ui.com/react/components/accordion) for more information.
