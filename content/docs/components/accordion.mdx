## Installation

```bash
npx shadcn@latest add https://odiaui.vercel.app/r/accordion.json
```

## Usage

```tsx
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@/components/ui/accordion";

export function Example() {
  return (
    <Accordion defaultValue={["item-1"]}>
      <AccordionItem value="item-1">
        <AccordionTrigger>Is it accessible?</AccordionTrigger>
        <AccordionContent>
          Yes. It adheres to the WAI-ARIA design pattern.
        </AccordionContent>
      </AccordionItem>
      <AccordionItem value="item-2">
        <AccordionTrigger>Can I open more than one?</AccordionTrigger>
        <AccordionContent>
          Yes. Add the `multiple` prop to the root to allow several items to
          stay open at once.
        </AccordionContent>
      </AccordionItem>
    </Accordion>
  );
}
```

## Variants

### Card

The default `card` variant renders each item as a separated rounded card with a
soft shadow and a primary accent bar that grows in when the item opens.

```tsx
<Accordion variant="card">...</Accordion>
```

### Flush

Use `flush` for a clean, divided list with no card chrome.

## Behavior

The trigger swaps its indicator for a circular icon button. When the panel
opens, the icon rotates and fills with the primary color. Panel height and
opacity animate with pure Tailwind transitions, and motion is disabled
automatically for users who prefer reduced motion.

## Subcomponents

- `Accordion` — the root container.
- `AccordionItem` — a single collapsible section.
- `AccordionTrigger` — the button that opens and closes an item.
- `AccordionContent` — the panel revealed when an item is open.

## Props

- `variant` — `card`, `flush`, or `odisha`. Defaults to `card`.
- `multiple` — allow several items to be open at the same time. Defaults to `false`.
- `defaultValue` / `value` — the item value or values that are open.
- `onValueChange` — called with the new value when an item opens or closes.
- `keepMounted` — keep closed panels in the DOM.
- `className` — additional classes merged with the default styles.
